# CineReview - ระบบรีวิวและจัดอันดับภาพยนตร์ (Tier List)

โปรเจกต์เว็บแอปพลิเคชันสำหรับบันทึก รีวิว และจัดอันดับภาพยนตร์ พัฒนาด้วย Laravel 11 และ Bootstrap 5 เชื่อมต่อข้อมูลภาพยนตร์จาก TMDB API พร้อมระบบจัดการสำหรับผู้ดูแลระบบ (Admin)

## ฟังก์ชันการทำงานของระบบ

- **ระบบภาพยนตร์:** ค้นหาและดึงข้อมูลภาพยนตร์อัตโนมัติจาก TMDB API
- **ระบบจัดอันดับ (Tier List):** ผู้ใช้สามารถสร้างกระดานและจัดลำดับภาพยนตร์ในระดับ S, A, B, C, D ได้เอง
- **ระบบรีวิวและให้คะแนน:** ให้คะแนน 1-10 พร้อมเขียนบทวิจารณ์ และตอบกลับความคิดเห็น
- **ระบบผู้ดูแลระบบ (Admin Panel):**
  - ตรวจสอบและอนุมัติภาพยนตร์ที่สมาชิกเสนอ
  - จัดการข้อมูลภาพยนตร์ หมวดหมู่ และแพลตฟอร์มสตรีมมิ่ง
  - ระบบกู้คืนข้อมูล (Soft Deletes)
  - จัดการรายงานคอมเมนต์ไม่เหมาะสม

## ขั้นตอนการติดตั้งและรันโปรเจกต์

### วิธีที่ 1: รันผ่านไฟล์ Script (สำหรับ Windows)
- รันโปรเจกต์: ดับเบิลคลิกที่ไฟล์ `run.bat` (ระบบจะตรวจสอบฐานข้อมูลและเริ่มรันเซิร์ฟเวอร์ให้อัตโนมัติ)
- รีเซ็ตข้อมูลใหม่ทั้งหมด: ดับเบิลคลิกที่ไฟล์ `setup.bat`

---

### วิธีที่ 2: ติดตั้งด้วยคำสั่ง Manual

1. ติดตั้ง Dependencies:
```bash
composer install
npm install
```

2. ตั้งค่า Environment:
```bash
copy .env.example .env
php artisan key:generate
```

3. สร้างฐานข้อมูลและรัน Seeder:
```bash
type NUL > database/database.sqlite
php artisan migrate:fresh --seed
```

4. เชื่อมโยง Storage:
```bash
php artisan storage:link
```

5. คอมไพล์ไฟล์ Frontend (Bootstrap 5):
```bash
npm run build
```

6. รันเซิร์ฟเวอร์:
```bash
php artisan serve
```
เข้าใช้งานได้ที่: `http://localhost:8000`
